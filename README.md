One word, the single word to erase from the dictionary forever. The program writes exactly that word to `/output/entry.txt` — floccinaucinihilipilification, the longest word in the dictionary, which itself means "estimating something as worthless". Deleting it is the dictionary doing exactly that to the word itself.

## Run it

```sh
python3 main.py
```
